## 3. Standard Implementations for Reference

### Standard Recursive Quick Sort (Python)

Quick Sort partitions elements **less than** and **greater than** a chosen pivot, then recursively sorts the sub-arrays:

```python
def quick_sort(arr):
    if len(arr) <= 1:
        return arr

    pivot = arr[len(arr) // 2]
    left = [x for x in arr if x < pivot]
    middle = [x for x in arr if x == pivot]
    right = [x for x in arr if x > pivot]

    # Recursively sort sub-arrays and concatenate
    return quick_sort(left) + middle + quick_sort(right)

print(quick_sort([5, 1, 3, 2, 4]))
# Output: [1, 2, 3, 4, 5]

```

### Standard Recursive Merge Sort (Python)

Merge Sort cleanly divides the list in half recursively without using any pivot or reshapes , then merges the sorted halves together using two pointers:

```python
def merge_sort(arr):
    if len(arr) <= 1:
        return arr

    mid = len(arr) // 2
    left_half = merge_sort(arr[:mid])
    right_half = merge_sort(arr[mid:])

    return merge(left_half, right_half)

def merge(left, right):
    result = []
    i = j = 0
    # Two-pointer merge pass
    while i < len(left) and j < len(right):
        if left[i] <= right[j]:
            result.append(left[i])
            i += 1
        else:
            result.append(right[j])
            j += 1
    result.extend(left[i:])
    result.extend(right[j:])
    return result

print(merge_sort([5, 1, 3, 2, 4]))
# Output: [1, 2, 3, 4, 5]

```
